# CSU正修訊息網 v1.0.0

適用於 `https://portal.csu.edu.tw/index.aspx`。可分別開關帳密填入與算式驗證值偵測。驗證圖只在登入頁內處理；不需連接第三方 OCR，也不會自動按「登入」。

## 已安裝舊版：更新方式

1. 在 Chrome 開啟 `chrome://extensions`，找到「CSU正修訊息網」，按卡片上的 **↻ 重新載入**。
2. 回到正修登入頁按 **Ctrl+R**。擴充功能的新程式只有在頁面重新載入後才會進入登入頁。
3. 打開插件，確認右下角顯示 **v1.0.0**。新安裝時兩個自動開關預設開啟。
4. 驗證圖片載入或更新後，插件會自動辨識並填入，不需要另外按偵測按鈕。

如果沒有看到 v1.0.0，可在 `chrome://extensions` 移除舊版，再用下方步驟重新載入本資料夾。移除擴充功能會清除原本儲存的帳密與開關設定，重裝後須自行重填。

## 首次安裝

1. 將整個 `csu-portal-autofill` 資料夾留在電腦上。若取得 ZIP，先解壓縮。
2. 在 Chrome 開啟 `chrome://extensions`，開啟「開發人員模式」，按「載入未封裝項目」，選擇本資料夾（內有 `manifest.json`）。
3. 點 Chrome 右上角的擴充功能圖示，開啟「CSU正修訊息網」。
4. 自行填寫帳號、密碼，點「儲存帳號與密碼」，再開啟需要的開關。
5. 開啟或重新整理 CSU正修訊息網登入頁，檢查帳密與驗證值後自行點「登入」。

## 注意

- 這一版會抓取驗證圖的原始 80×30 像素，在本機分割三個字元後計算算式並填入數值，即使信心較低也會填入，插件會提示「請特別核對」。圖片雜訊或網站改版仍可能讓結果出錯，請先對照算式再登入。
- 若你手動修改驗證值，插件會保留你的輸入；重新換圖後會自動重新辨識。
- 帳號與密碼儲存在 Chrome 擴充功能的本機儲存空間，**未另外加密**。共用電腦不建議儲存密碼。
- 沒有預設使用任何截圖中的帳號或密碼；只有你自行輸入並按「儲存」才會保存。

`model-data.js`、`detector.js` 和 `content.js` 直接在登入頁執行辨識與填入；`popup.html`、`popup.js`、`popup.css` 提供設定介面。
